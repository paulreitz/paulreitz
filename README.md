## About Me
I am a front-end engineer with 15 years shipping interactive products: Halo Channel for Xbox One, HBO Go, and Minesweeper for Teams. Lately I've been building open-source tooling in SolidJS and TypeScript.

Open to front-end / UI engineering roles.

## Preferred Tech Stack
- **UI:** Angular, SolidJS
- **App Framework:** SolidStart (SSR)
- **State:** Signals
- **Streams:** RxJS
- **Database:** PostgreSQL, Drizzle ORM
- **Hosting:** Cloudflare, Neon
  
### Notes
- **RxJS:** Event Streams: debounce, key filters, subscription lifetime - not a state manager.
- **Drizzle:** TypeScript ORM: code-first schema and migrations.
